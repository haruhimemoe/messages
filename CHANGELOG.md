# Changelog

All notable changes to `@haruhimemoe/messages` are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.2.8] - 2026-10-12

### Added

- `tourney`: strings for the Notifications settings tab (webhook targets, event routes, reminder hours, failed and waiting deliveries) and event names.

### Added

- `tourney`: strings for the Notifications tab (Discord webhooks, which events go where, match reminders and failed notifications) and the event names.

## [0.2.7] - 2026-10-12

### Added

- `tourney`: strings for embeds (widget labels, empty state, the embed code builder and Embeds page), the schedule list zone line and match map labels.

## [0.2.6] - 2026-10-12

### Added

- `tourney`: strings for roles and permissions, the Staff tab, the audit log, confirmations and hidden-edition hints.

## [0.2.5] - 2026-10-11

### Added

- `bb`: strings for snippets (the Snippets tool, saving and importing snippet files) and the `snippet` template kind.

## [0.2.4] - 2026-10-11

### Added

- `bb`: strings for template proposals: proposing from a fork, withdrawing, and merging or declining on the original.

## [0.2.3] - 2026-10-11

### Added

- `bb`: strings for the editor's Variables tool.

### Changed

- `bb`: the template form's body hint mentions `{{#key}}...{{/key}}` sections.

## [0.2.2] - 2026-10-11

### Added

- `bb`: strings for the toolbar's tool groups and the Emoji, Table and Art tools, and the flag picker's recent and all lists.

## [0.2.1] - 2026-10-11

### Added

- `bb`: strings for the editor's settings, the problem summary with Fix all, and the profile hover card.

## [0.2.0] - 2026-10-11

### Added

- `bb`: strings for the editor's Markdown and Import tools.

## [0.1.0] - 2026-10-11

### Added

- English catalogs and the loader: `loadMessages`, `messagesLoader`, `LOCALES`, `NAMESPACES`, `DEFAULT_LOCALE`.
- `messages-check-keys`, a command that checks an app's translation keys against the English catalogs.
